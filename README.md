# Dogfight Threat AI

一个 2D 俯视空战小游戏。

玩家驾驶战机在战场中飞行、射击与规避。敌方 AI 会根据战场态势调整行为，而不是按固定航线或简单触发规则行动。AI 的行为设计参考《最后生还者》中敌人 AI 的思路，在搜索、追击、攻击与规避之间切换。

项目规模较小，用于验证飞行手感与动态 AI 决策行为。

## 主要特性

- 2D 俯视空战，包含惯性滑行、转向阻尼与漂移。
- 实时威胁评估：将战场划分为网格，根据敌我位置、弹幕与导弹状态计算威胁值。
- 敌方 AI：巡逻、搜索、追击、攻击、规避等行为动态切换，配合行为树与路径规划。
- 武器：机炮与导弹，追踪导弹作为后续目标。
- 联机：服务器权威与客户端同步，规划中。

## 技术栈

- Unity 2022.3 LTS
- C#
- 2D，Built-in Render Pipeline
