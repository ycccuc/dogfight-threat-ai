## 四、场景接线（`Assets/_Project/Scenes/Battle.unity`）

**不用手拖**：跑菜单 **`Dogfight → 搭建或刷新 Battle 场景`**。
它会用代码把下面这些对象建好 —— 幂等（重复执行不重复创建，也不删你手动加的东西），
而且场景结构因此变成可 review 的代码，而不是一坨读不懂的 YAML。

它会创建 / 更新的对象：

```
Battle
├── Main Camera            ← 已存在，改设置 + 挂组件
│   └── (CameraFollow)      Orthographic / Size 11.25 / 背景深色
├── MatchLoop              ← 空物体，挂 MatchLoop
├── Plane_Player           ← 玩家机
│   ├── SpriteRenderer       Sprite = ship_0000，Sorting Layer = Units，Order = 0
│   ├── Rigidbody2D          Gravity Scale 0 / Linear Drag 0.8 / Angular Drag 0
│   │                        Interpolate / Continuous
│   ├── CircleCollider2D     Radius ≈ 0.4
│   └── PlaneAgent           Agent Id 0 / Team 0 / Player Controlled ✅
│                            Flight Profile = FlightProfile_Player
└── (视差背景)              ← W1 后半段做，见第六节
```

**搭建工具已经做掉的**：飞机与相机的 Rigidbody2D / Collider / 排序层、相机 orthographic size、
`MatchLoop.Planes` 数组的接线、三个视差层对象与系数。

**还需要你手动做的只有一件事**：把贴图拖上去。
搭建日志里会明确列出「`Plane_Player` 还没有贴图」这类提示，按提示拖即可。

> 飞行参数留空时，`PlaneAgent` 会用 `FlightSpec.Default`（与暑期原型等价的数值），
> 所以不建配置资产也能直接试飞；想调参再 Create → Dogfight → 飞行参数。

**先不要放敌机**：W1 的第一目标是手感，敌机属于 ③ 武器系统那一步。

## 五、手感调参顺序（重要）

按这个顺序调，每次只动一个参数并立刻 Play 试飞，把结果记到下面的表里：

| 顺序 | 参数 | 调它的目的 | 参考初值 |
|------|------|-----------|----------|
| 1 | `Linear Drag`（Rigidbody2D） | **手感的核心旋钮**：松油门后滑行多久 | 0.8 |
| 2 | `Thrust` | 起步猛不猛 | 22 |
| 3 | `Max Speed` | 极速；太快会来不及反应 | 9 |
| 4 | `Turn Rate` | 掉头快慢 | 260 °/s |
| 5 | `Turn Accel` | 转向"干脆"还是"飘" | 1800 °/s² |
| 6 | `Stall Speed` + `Stall Penalty` | 低速时是否变钝（**这是"飞机感"的关键**） | 1.5 / 0.6 |

**验收标准**（W1 的核心交付）：**同一套按键输入，能明显感觉出"飞机"而不是"平移的小人"**。
具体表现为：松油门有惯性滑行；转向有延迟且高速转向会画弧；低速掉头明显变钝。

调完把最终数值填回 `FlightProfile_Player`，并在此表记录：

| 参数 | 最终值 | 一句话感受 |
|------|--------|-----------|
| Linear Drag | | |
| Thrust | | |
| Max Speed | | |
| Turn Rate | | |
| Turn Accel | | |
