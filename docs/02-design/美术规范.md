# 美术技术规范

> 状态：**草稿** · 2026-10-05
> 目的：定一条**基线**。以后只有匹配这条基线的素材才允许入库，其余一律不用。
> 没有基线的后果：素材越攒越乱，尺寸/像素密度/视角全不一样，返工成本远大于画图本身。

---

## 一、基线（先记住这张表）

| 项 | 值 | 说明 |
|---|---|---|
| 设计分辨率 | **1280 × 720**（16:9） | UI 与相机按此设计 |
| Pixels Per Unit | **32**（全局统一） | 由 `PixelArtPostprocessor` 自动设置，不靠手改 |
| 相机 Orthographic Size | **11.25** | = 720 ÷ 2 ÷ 32，可视高度 22.5 世界单位 |
| Tilemap Cell Size | **0.5** | 16px 地形块 ÷ PPU 32 |
| 像素密度基准 | **32 × 32** | 飞机 32px 占 1×1 世界单位；16px 地形占 0.5×0.5 |
| 过滤 / 压缩 | Point / 不压缩 / 无 mipmap | 已由导入后处理器固化 |

> 为什么 PPU 定 32 而不是给飞机和地形各定一套：**只有一条规则**最不容易出错。
> Kenney Pixel Shmup 里飞机是 32×32、地形是 16×16，统一 PPU=32 之后地形自然成为半格，
> 对地形格来说正合适。

**相机设置**：`orthographic = true`，`Orthographic Size = 11.25`；
如需像素完美再加 `Pixel Perfect Camera`（Assets PPU = 32，Reference Resolution = 1280×720）。

## 二、排序层（Sorting Layers）

顺序 = 渲染先后（靠前的先画）。**已由 `Dogfight → 项目初始化` 自动创建，不要再手工加层。**

| 层名 | 放什么 |
|------|--------|
| `Background` | 最远层天空 / 海面 |
| `Far` | 视差第 2 层云 / 远山 |
| `Mid` | 视差第 3 层云 / 岛屿 |
| `Near` | 视差最近层，掠过感最强 |
| `Ground` | Tilemap 地形、障碍 |
| `Units` | 飞机（含玩家与敌机） |
| `Projectiles` | 子弹、导弹 |
| `VFX` | 爆炸、尾焰、命中特效 |
| `UI` | HUD 与雷达（Canvas 用 Screen Space - Overlay，独立于世界排序） |

`Order in Layer` 约定：同层内 `0` = 玩家、`10` = 敌机、`20` = 精英 / BOSS，留出插入空间。

## 三、命名规范

| 类型 | 规则 | 示例 |
|------|------|------|
| 玩家机 | `ship_player_<序号>_<尺寸>.png` | `ship_player_01_32x32.png` |
| 敌机 | `ship_enemy_<型号>_<尺寸>.png` | `ship_enemy_scout_32x32.png` |
| 子弹 | `bullet_<武器>_<尺寸>.png` | `bullet_cannon_8x8.png` |
| 爆炸序列帧 | `vfx_explosion_<大小>_<帧号>.png` | `vfx_explosion_small_00.png` |
| UI | `ui_<用途>.png` | `ui_radar_frame.png` |
| 音效 | `sfx_<对象>_<动作>.wav` | `sfx_cannon_fire.wav` |

> 代码里**不写这些文件名**。取图一律走 `SpriteBankSO` 的语义键。

## 四、素材准入检查清单（6 条，缺一不收）

- [ ] **视角**是俯视 top-down（侧视素材一律不要 —— 会削弱网格类算法的可视化效果）
- [ ] **尺寸符合 PPU 32 基线**（或明确记录需要怎么换算）
- [ ] **成套**：不只是飞机，还含子弹 / 爆炸 / 背景分层 / UI / 音效，或至少说明缺什么
- [ ] **授权干净**：CC0 > CC-BY（需署名）> 付费 EULA；**不接受**「仅学习用 / 禁止商用」
- [ ] **可拆层**：背景能拆 2–3 层做视差；爆炸是多帧序列图而非单图
- [ ] **已登记**到 `docs/素材台账.md`（来源 URL + 授权 + 是否需署名）

## 五、入库流程

```
第三方素材 → art-source/third-party/<包名>/source/     （原始归档，不导入 Unity）
           → 挑出要用的图，拷进 Assets/ThirdParty/<包名>/  （PPU 等由后处理器自动设）
           → 在 SpriteBankSO 里把语义键指向它们
自产素材   → art-source/original/<类型>/                （保留 .aseprite / .psd 源文件）
           → 导出图拷进 Assets/_Project/Art/
```

**源文件不在 Unity 工程里改**：Unity 工程里只放导入后的资源，避免改了源图找不回来。
`source/` 目录里的 `Preview.png`、`Sample.png`、`*.url`、`Tilesheet *.txt` **不要**拷进 Unity。
