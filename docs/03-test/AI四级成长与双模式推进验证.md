# 四级成长与双模式推进验证

日期：2026-10-24。当前版本沿用基础接触战斗，重新加入四级成长，并重做玩家推进手感。旧 `AttackRunInputSource` 停车/重占位方案仍保留作历史，不是 Battle 默认输入源。

## 点按与长按

| 操作 | 实际规则 |
|---|---|
| 点按 Shift | 按下立即预付 0.18 槽，完成约 0.2 秒、2.4 倍的短促冲刺，松开不截断已经支付的短爆 |
| 按住 Shift | 短爆后继续推进，约 0.8 秒升至 3 倍，目标速度 27；满槽连续推进约 2.92 秒 |
| 松手 | 用 0.26 秒逐步回落倍率，不立刻夹回普通速度；尾段仍提供推进来遵守下降后的真实速度 |
| 回能 | 停推 0.5 秒后开始回充，3 秒回满；耗尽须松开再按 |
| 冷却内重按 | 保持按住则排队至最短 0.36 秒间隔结束后付费起爆；提前松开、S 或死亡取消排队 |
| S 刹车 | 优先于 W/Shift，取消短爆和尾推并允许回能；Shift 未松不能自动重启 |

冲刺不赋予无敌。接触仍每次扣 1 HP、受击保护 0.7 秒，视图抖动不改变根碰撞体和相机稳定位置。

## 四级成长

| 等级 | 自动时间 | 观察延迟 / 刷新间隔 | 主要能力 | 恢复 |
|---|---|---|---|---|
| Lv1 | 0 秒 | 0.18 / 0.16 秒 | 追踪已经观察到的位置，反应较慢 | 1.8 秒 |
| Lv2 | 20 秒 | 0.12 / 0.12 秒 | 根据历史速度做有上限的截击预测 | 1.6 秒 |
| Lv3 | 40 秒 | 0.08 / 0.08 秒 | 保持稳定侧别的侧向切入，减少纯追尾 | 1.4 秒 |
| Lv4 | 60 秒 | 0.04 / 0.06 秒 | 根据历史转弯曲率及置信度适应重复绕圈，预测有界 | 1.2 秒 |

所有等级共享 0.8 秒满速移动瞄准、0.9 秒内的五倍直线冲撞、真实机头锁向与碰撞体积。等级只在追踪/恢复结束的边界更新，正在进行的瞄准、冲撞和恢复不会因升级改变参数。没有准备点到达判定、停车等待或冲撞开始后继续修正航向。

观察记忆不读取 Shift、玩家能量、下一帧输入或未来轨迹。黄线严格显示当前观察预测点的方向，所以高级预测线可能指向玩家前方；它不是实时真值泄漏或已经锁定的航道。F1-F4 或 HUD 按钮固定选择等级，F5/AUTO 恢复自动成长；选择在下一攻击边界生效。死亡后 R 重开，再选预览等级。

本轮重新核对了 Travis McIntosh 的 [GameAIPro2 第34章原文](https://www.gameaipro.com/GameAIPro2/GameAIPro2_Chapter34_Human_Enemy_AI_in_The_Last_of_Us.pdf)：34.3 的带时间戳记忆，34.5 的职责分层，34.8 的稳定战斗方向。应用为有限观察、独立预测/阶段/飞行输入和本轮稳定侧别。[GDC2021 Melee AI 官方讲义](https://media.gdcvault.com/GDC+2021/Melee+AI+in+The+Last+of+Us+Part+II.pdf) 的前兆与动作事件原则用于保留可读预警、锁向冲撞和扑空恢复。
