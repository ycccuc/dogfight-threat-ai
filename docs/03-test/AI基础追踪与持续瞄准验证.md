# 基础追踪与持续瞄准原型

日期：2026-10-24。用户要求撤回复杂成长逻辑，重新做“持续追踪 → 范围内持续瞄准 → 到时冲撞”的基础版。本记录保存当时的基础版验收；当前 Battle 已由 [碰撞体积与五倍冲撞验证](AI碰撞体积与五倍冲撞验证.md) 更新，以下为历史行为。

## 当前规则

| 阶段 | 行为 |
|---|---|
| 追踪 | 满油门朝玩家当前模拟位置转向，持续接近；不选准备点、不保持攻击距离、不切侧翼 |
| 持续跟瞄 | 距离≤8且两机可见时开始；移动目标速度3，持续0.8秒，黄色细线实时指向玩家；玩家移动或短暂出屏不会重置计时 |
| 冲撞 | 跟瞄计时结束时锁定实际机头；满油门直线飞行最多0.9秒，红色显示真实剩余轨迹和全宽2的危险边界 |
| 恢复 | 命中或冲撞结束后飞离1.2秒，靠墙时转回场内；时间一到回到追踪，不等待精确坐标或最小分离距离 |

跟瞄期间不是锁定航线，只有冲撞阶段锁向和授权伤害。保留5HP、每攻击编号最多1点伤害、2秒受击无敌、死亡与R重开；无敌期内继续追踪，暂不开始新跟瞄。所有阶段使用现有FlightModel，敌机上限9、转速210不变。

## 实现范围

- 新 `Scripts/Core/AI/PursuitChargeInputSource.cs` 是Battle默认输入源，由现有 `Gameplay/Input/ChaseAiInputSource.cs` 接线，场景/prefab引用无需重建。
- 默认Battle停用四级成长、侧翼、截击、延迟观察、逃生搜索准入和反复准备点；HUD移除等级，明确显示持续跟瞄与冲撞锁向。
- 黄色阶段只显示实时瞄准方向线，不伪装成已经承诺的危险区域；红色阶段才显示由真实飞行积分生成的剩余冲撞预览。
