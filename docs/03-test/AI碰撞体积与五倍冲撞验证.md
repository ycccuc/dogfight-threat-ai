# 飞机碰撞体积与五倍冲撞验证

日期：2026-10-24。本记录保存当时验收；当前 Battle 继续由 [绕后瞄准与玩家冲刺验证](AI绕后瞄准与玩家冲刺验证.md) 更新。该轮按用户要求调整基础追踪版；此前的减速瞄准、红色冲撞轨迹、仅冲撞阶段伤害和 2 秒无敌已由本记录替代。

## 当前行为

| 项目 | 规则 |
|---|---|
| 追踪与瞄准 | 持续追踪；距离不超过 8 且可见时进入 0.8 秒实时跟瞄，满油门，普通速度上限 9，不再指定低速瞄准 |
| 冲撞 | 瞄准结束锁实际机头，直线冲撞最多 0.9 秒；临时速度倍率 5，目标速度 45，拖曳后的固定步速度约 44.910 |
| 提示 | 保留黄色动态瞄准线；冲撞时不显示红色轨迹、箭头和危险区域边线 |
| 碰撞体积 | 两机根物体各有半径 0.5、中心偏移为零的 CircleCollider2D 与 AircraftHitbox；Art 插值和抖动不改变体积 |
| 伤害 | 5 HP，每次有效接触扣 1；各阶段都能接触伤害，不依赖攻击编号。满速瞄准时提前碰到玩家也会扣血并触发飞离 |
| 受击 | 0.7 秒无敌，短暂变红和闪烁；仅本机 Art 抖动 0.18 秒，镜头使用未抖动的插值位置 |
| 后续 | 命中或冲撞结束后飞离 1.2 秒，再追踪；死亡停止，R 重新开始 |

FlightModel 继续拥有飞行状态，CircleCollider2D 使用 trigger 定义体积，不让第二套物理解算器推开飞机。战斗模型读取两体积当前实际半径，并对同一固定步两机相对运动做连续圆扫掠；冲刺一帧穿过、端点均不相交时也能判定。关闭任一碰撞体或 AircraftHitbox 时不扣血，战斗时钟与无敌倒计时继续推进。无敌到期仍接触则允许再次受伤。
