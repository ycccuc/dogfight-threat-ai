# 追赶推进、资源惩罚与四级难度验证

2026-10-24。本轮根据用户批准的[实施计划](../superpowers/plans/2026-10-24-pursuit-boost-resource-difficulty-plan.md)实现；最终自动化回归与原生键盘试玩分别记录，以下不把中间调参结果当成最终通过。

## 已实现的规则

- Shift 按住线性长推，Space 按下边沿立即短冲；普通 WASD 操控保留。
- 玩家60能量；短冲25、21.6速度、0.18秒、1.2秒起手冷却；长推40/秒、实际前速9以上每秒增加7.5至18。松手按30/秒²有限退出。
- 正常停推0.7秒后20/秒回能。已获准消费耗尽后0.9秒过热，禁推进和回能，以有限减速靠近7.2；保留转向和刹车。短冲不附带无敌。
- 敌机60追赶能量、起手30、停推0.8秒后15/秒回能；推进和退出转向限制90°/秒。升级不回满资源或重置冷却。
- 进入范围且完整可见后，0.8秒移动瞄准；突然从高速追赶交接时保留入口速度的快照。Charge沿真实机头锁向，阻尼后绝对45，最长0.9秒；扑空和接触后有完整恢复，重复接触不延长恢复。
- 两机真实体积接触扣1HP；5HP、0.7秒无敌、Art抖动与稳定相机保留。

## 验证方法与边界

生产运动只由FlightModel写入。新的命令区分普通惯性、有限加速和定速覆盖；资源按可支付的步内时间授权，测试包含0.01/0.02/0.0333秒固定步。

纯Core压力对照为四级×12初态×8策略，正常5HP、每局最长60游戏秒、无边界。初态为距离12/18/24、玩家朝向0/90°、敌机左右偏移±2；各级同一组初态。记录首次可见预警、生存、命中、双方推进与过热。玩家始终在跟随相机内；仅敌机进入矩形可见范围才允许预警。矩形近似不能替代Unity真实相机。

八种策略为静止、直飞、左右固定绕圈、CD一好就短冲、持续长推至耗尽、预警换向加晚短冲、管理能量推进加换向。响应策略只用当前公开阶段，不读敌机未来路径，使用真实玩家资源和CD。60秒仍活记为删失，未出现预警记为-1，不能解释为60秒时一定追到。

旧版基线在改生产Core前复制保存，仍使用当时同Shift输入语义；因此对照既包含AI变化，也包含批准的玩家推进调整，不能把全部差异归因于单一AI算法。

可重跑当前压力矩阵：

```powershell
dotnet run --project tools/DogfightThreatAI.BalanceProbe/DogfightThreatAI.BalanceProbe.csproj -- TestResults/balance-matrix.json
```

原生键盘试跑使用操作系统SendInput，经正常KeyboardInputSource进入Battle；临时观察器只读实际按键、焦点、位置、血量和资源，不替换玩家输入，不改血量或坐标。驾驶脚本读取阶段、剩余预警、位置和当前资源，决定按键。它验证真实键盘输入链路，但不是人工手打、也不能证明人能靠画面稳定做到最后0.12秒短冲。原生测试与Core脚本策略分别报告。

有效11局按runId、session及起止实时时间截取；启动失败、混入用户按键或焦点丢失的早期重试不计。以下有效区间焦点一直在Unity，按键符合策略，固定等级未偏离。没有改HP、坐标或AI状态来制造成绩。

| 场景 | 实际输入与结果 |
|---|---|
| 点按与CD | Space按键在游戏采样中约80毫秒（对应观察采样实时间隔约92毫秒）；实际短冲21.6、扣25。CD内再点不扣费、不排队，后续新按下可再次触发；4秒5HP→5HP |

推进、资源惩罚、四级运行时能力、预警与锁向、真实接触和反制输入链路已实现并通过上述回归。原生对照可见四级压力更高，主动换向和保留能量有实际收益；量化平衡尚未全部达标，尤其是四级25秒绕圈目标、部分直飞/静止初态和小步长反应窗口。
