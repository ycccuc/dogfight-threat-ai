# 代码排版与注释验证

日期：2026-11-02。

## 本次范围

- 检查项目自有 C# 文件 149 个，实际更新 141 个。
- 覆盖 Core、Gameplay、UI、编辑器工具、EditMode/PlayMode 测试，以及两个控制台工具。
- 统一四空格、LF、另起一行的花括号；展开条件/循环与方法体，拆开同一行的多个操作。
- 补充 332 处方法用途与关键逻辑说明，保留原有注释。
- 更新 `.editorconfig`、VS Code C# 保存格式化设置和项目排版说明。大厅 Shader 的 Tags 块仅作排版调整。

## 结构检查

对整理前的当前工作区源码保留临时副本，使用 C# 语法树处理分支和方法体，不以简单文本替换批量添加花括号。

分别检查普通编译、UNITY_EDITOR、LEGACY、UNITY_EDITOR + LEGACY 四种条件。统一表达式方法体与块级方法体的比较形式后，149 个文件的代码 token 序列一致；原有普通注释保留，分支和循环的花括号检查通过。

所有检查范围内的 C# 文件使用 LF，未发现行尾空白。未重命名序列化字段、移动脚本或改动玩法数值。
