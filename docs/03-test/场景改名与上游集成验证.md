# 场景改名与上游集成验证

记录日期：2026-10-25。本记录用于 `feat/chase-ai-prototype` 集成上游 `origin/main`（`90ea025`）后的独立复验，并随现有 [PR #1](https://github.com/ycccuc/dogfight-threat-ai/pull/1) 更新。以下结果来自本轮隔离副本的新复跑，原始报告、脱敏副本及源码一致性均已核对。

## 集成原因与范围

上游新增开始界面、河谷农田地图和双向导航，并将原 `Menu` / `Battle` 场景分别更名为 `StartMenu` / `GameScene`，保留原场景 `.meta` GUID。AI 分支原有路径、编辑器直玩入口和场景测试需要适配，同时将单敌机玩法与上游地图、菜单合入同一 GameScene。

现行场景与入口如下：

| 项目 | 本轮约定 |
|---|---|
| 完整游戏入口 | `Assets/_Project/Scenes/StartMenu/StartMenu.unity`，Build Settings 索引0 |
| 实际战斗场景 | `Assets/_Project/Scenes/GameScene/GameScene.unity`，Build Settings 索引1；Battle继续作为玩法名 |
| 常规编辑器Play | `GameEntrySetup`从StartMenu启动，任意键显示菜单，再开始进入GameScene |
| 双向导航 | StartMenu开始→GameScene；右上角返回→StartMenu；再次开始创建新对局 |
| AI直玩工具 | `Tools → Dogfight Threat AI → Open Battle and Play`临时直入GameScene，退出Play后恢复StartMenu入口 |
| 物理与背景边界 | 物理战场400×300，相机世界半尺寸(201.2,151.2)；2单位背景外沿仅用于渲染，不扩大物理边界、不参与碰撞、不改伤害 |
