# 开始界面使用说明

开始界面以项目负责人提供的背景图为底图，使用右侧文字菜单，保留左侧主体画面。菜单只负责导航与本地表现设置，不持有对局状态。

## 运行

1. 使用 Unity 2022.3 打开 `src/client/DogfightThreatAI`。
2. 打开 `Assets/_Project/Scenes/Menu/Menu.unity`，进入 Play。
3. 按任意键或点击鼠标。提示文字在 0.35 秒内消失，菜单在 0.65 秒内显示。
4. 点击“开始游戏”。画面淡黑后异步加载 `Assets/_Project/Scenes/Battle/Battle.unity`。

Menu 与 Battle 已位于项目的 Build Settings，顺序保持原样。原生 Canvas、背景、标题、按钮、事件系统和控制器引用保存于 Menu 场景，可在 Hierarchy 中直接查看。进入 Play 后控制器恢复初始提示状态。直接运行 Battle 场景时不会创建菜单；返回 Menu 场景会重新显示任意键提示。

目前 Battle 仍为原项目的飞行原型；开始界面不增加武器或 AI 玩法。

## 菜单和面板

| 项目 | 行为 |
|---|---|
| 开始游戏 | 淡黑并异步切换到实际 Battle 场景；过渡中屏蔽重复操作 |
| 设置 | 打开主音量、显示模式、垂直同步与减少动态效果的设置面板 |
| 操作说明 | 展示当前真实存在的 WASD 飞行操作及菜单快捷键 |
| 制作名单 | 展示项目组、引擎、背景来源与字体信息 |
| 退出游戏 | 先确认；取消会恢复菜单焦点。编辑器中停止 Play，独立包退出应用 |

鼠标可点击菜单和控件；上下方向键或 Tab 选择，Enter / Space 确认，Shift+Tab 反向选择。设置中的音量滑块支持左右方向键。Esc 关闭面板，在主菜单按 Esc 打开退出确认。

面板打开时，主菜单不接受操作；关闭面板后恢复到原菜单项目。用于跳过初始提示的按键不会同时触发开始游戏。

## 设置

| 设置 | 生效方式 |
|---|---|
| 主音量 | 应用后设置 `AudioListener.volume`，对菜单和后续场景的声音均有效 |
| 显示模式 | 无边框全屏或窗口模式；由 `Screen.fullScreenMode` 控制 |
| 垂直同步 | 由 `QualitySettings.vSyncCount` 控制 |
| 减少动态效果 | 关闭提示呼吸动画，并立即完成后续界面过渡 |

所有设置先修改草稿。点击“应用设置”才生效，并写入 `PlayerPrefs` 的 `Dogfight.Menu.*` 键；Esc 或“返回”会放弃未应用的更改。“恢复默认”同样需要再次点击应用。

首次启动不强制改变用户的显示模式。已保存的音量、显示和垂直同步设置在游戏启动时恢复。

## 代码与资源

- `Scripts/UI/Menu/MainMenuController.cs`：场景接入、界面构建、淡入淡出、输入门控和面板流程。
- `Scripts/UI/Menu/MenuUi.cs`：字体、UI 控件、焦点与布局辅助。
- `Scripts/UI/Menu/MenuItemFeedback.cs`：统一鼠标和键盘的选中反馈。
- `Scripts/UI/Menu/MenuPreferences.cs`：表现设置草稿、应用与本地保存。
- `Scripts/UI/Menu/MenuShade.cs`：原生 UI 顶点渐变遮罩，可随场景保存。
- `Editor/MenuSceneAuthoring.cs`：使用编辑器生成、保存和预览原生 Canvas 的工具。
- `Scripts/UI/DogfightThreatAI.UI.asmdef`：独立 UI 编译边界，引用 uGUI，不依赖 Core 或 Gameplay；供菜单流程测试引用。
- `Resources/Menu/Background.jpg`：项目负责人于 2026-10-24 提供的背景图，保留原图；可读性遮罩在运行时叠加。
- `Resources/Menu/Fonts/MenuChinese.ttf`：Noto Sans SC 的静态字重 400 子集，重命名为 Dogfight Menu Sans，包含当前界面文字。
- `Resources/Menu/Fonts/BebasNeue.ttf`：英文标题字体。

字体来源为 Google Fonts 官方仓库的 [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 与 [Bebas Neue](https://github.com/google/fonts/tree/main/ofl/bebasneue)，两份 SIL OFL 1.1 原始许可证与字体一同保留。字体许可证只适用于字体。后续新增中文文案时，需要补充中文字体子集中的字形。

菜单 Canvas 采用 1920×1080 参考尺寸，适配不同宽高比；背景铺满屏幕，超宽屏下菜单会适当缩放以避开底部提示。

## 验证

在 Unity Test Runner 的 PlayMode 页签运行 `DogfightThreatAI.Tests.Menu`。四项测试覆盖初始输入与过渡门控、模态面板隔离及焦点返回、取消设置草稿、操作说明与制作名单返回路径。

在编辑器菜单 `Tools → Dogfight Threat AI` 中，可切换“预览初始界面”和“预览主菜单”，无需 Play 即可检查场景布局。“重建开始界面布局”会重新生成控制器管理的 UI 层级，支持 Undo；已有的自定义布局应先保存备份。运行时面板由同一套原生 uGUI 控件创建。

测试执行情况见 [开始界面验证记录](../03-test/开始界面验证.md)。
