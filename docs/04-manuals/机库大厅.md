# 机库大厅

第一版为本地可移动大厅原型。场景显示“本地预览”，尚未接入 Mirror、网关、房间号或远程玩家。

## 进入与操作

- 从 `StartMenu` 选择“联机大厅”，进入 `LobbyScene`。
- W / ↑ 推进，S / ↓ 刹车，A/D / ←→ 转向；松开推进键会减速停下。
- Esc 返回主菜单。大厅没有战斗、武器和胜负结算。

场景路径：`Assets/_Project/Scenes/LobbyScene/LobbyScene.unity`。Build Settings 保持 StartMenu、GameScene 的原有顺序，在最后追加 LobbyScene。

## 内容与配置

- 地图采用已导入的 Kenney Pixel Shmup 素材，64 × 36 格，每格 0.5 世界单位。`Lobby map/Ground (editable Tilemap)` 是原生 Tilemap，可在编辑器继续绘制。
- 四个停机位和北侧空地为内容扩展留位；北侧当前没有传送门或触发逻辑。
- `Settings/Lobby/Lobby.asset` 保存活动边界、地图尺寸、出生点和机身显示宽度。出生点数组长度决定容量显示。
- `Settings/Lobby/LobbyAircraft.asset` 独立保存大厅移动参数和美术引用，不修改战斗机型配置。
- `Settings/Lobby/Terrain.mat` 的 Saturation / Brightness 控制大厅地形配色；战斗地图不使用这个材质。
- `Spawn points (configuration markers)` 是配置生成的可视化定位参考，实际出生位置以 Lobby.asset 为准。

## 代码边界

| 代码 | 职责 |
|---|---|
| Core/Lobby/LobbySimulation | 持有前后两步飞行状态，用 FlightModel 推进移动与边界约束 |
| Gameplay/Input/LobbyInputSource | 采集操作和焦点状态，输出 FlightInput |
| Gameplay/Lobby/LobbyController | 本地驱动接线：输入 → 模拟 → PlayerView / HUD |
| Gameplay/Lobby/LobbyCamera | 按屏幕比例容纳完整地图，不改变活动范围 |
| UI/Lobby/LobbyHudView | 显示成员数量、本地标记、操作提示，发出退出事件 |
| Editor/LobbySceneAuthoring | 使用 Unity 序列化生成场景、原生地图和菜单入口 |

UI 不引用 Core/Gameplay；模拟不引用 Unity、视图或网络。当前控制器只驱动一架本地飞机，并不表示多人房间已实现。

## 后续接网

客户端上传操作，由权威服务器维护房间成员和飞机状态；网络适配放入 Scripts/Network，共享协议放入 src/shared/Protocol。用远程快照驱动视图时，应停用对应本地模拟驱动，避免两个写入者同时修改同一架飞机。

准备、房间号、开始权限和传送门需由后续房间规则与服务器确认结果驱动，不应写进 HUD 或地图视图。

## 重建

首次构建可用菜单 `Tools → Dogfight Threat AI → 构建机库大厅`。构建工具通过 Unity 正式保存资产，并恢复原活动场景。

重建会覆盖大厅生成内容和独立配置中的默认机型参数；手动修改地图后不要随意重建。已打开 LobbyScene 时工具拒绝重建，避免覆盖现场编辑。日常修改请直接编辑已有场景与配置。
