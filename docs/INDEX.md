# 项目文档索引

[返回项目首页](../README.md)

本目录用于存放项目级文档。文件夹说明、GitHub 模板等具有固定位置要求的文件不在此列。

## 成员阅读顺序

1. 阅读本文档索引。
2. 阅读 [架构约定.md](02-design/架构约定.md) 第二节“总体架构思路”和第三节“程序集与分层”。
3. 阅读 [Player移动说明.md](02-design/Player移动说明.md) 第一、二、三节，了解一条完整的数据流。
4. 阅读 [架构约定.md](02-design/架构约定.md) 第五节“目录结构”，确认新代码放在哪里。

阅读后应能回答以下问题：

- 新增一架飞机需要修改代码吗？
- View 能否直接修改血量或位置？
- Core 中能否引用 UnityEngine？
- 新增一种网络输入源应实现哪个接口？
- 修改场景或 prefab 后需要做什么？
