# 接触攻击循环实施计划

**目标：** 玩家停车也会被敌机追上并碰撞扣血；受击无敌期间敌机飞离、重新占位，再次攻击。战斗时间越长，敌机速度、转向和预判逐步增强。

**架构：** 保留已有纯 C# 跟随控制器及间距回归测试。新增攻击状态机只读取世界与战斗快照、输出 FlightInput；独立接触模型基于双方真实固定步相对扫掠处理伤害和无敌。Unity 只负责接线、显示血量/无敌/阶段及重试。

**参考：** 已检索 B 站 BV11JTMe6EtN《最后生还者》人类敌人 AI GDC 讲座，并核对 Naughty Dog 官方讲座说明。借鉴将战斗行为组合成明确决策的设计方向；本项目的撞击、飞离、难度参数是针对飞机玩法的独立实现。

- [x] 子代理独立复现旧行为：2.2 单位附近永久停车；3000 静止初态和1500停车轨迹未发现远处永久停滞。
- [x] 按用户最新澄清更新规格：接触攻击取代 Battle 默认保持两单位间距。
- [x] ContactCombatModel：先测扫掠命中、无敌、死亡和无效输入，再实现；伤害入口唯一。
- [x] AttackRunInputSource：先写真实 FlightModel 闭环回归；实现追击、飞离、重攻、丢失目标四阶段。逃离点在边界内，玩家无敌时重新占位。
- [x] Unity Battle 接线：独立敌机配置、晚于飞行更新的接触系统、HP/无敌反馈、R 重试。
- [x] .NET 126/126、Unity EditMode 126/126、Battle PlayMode 8/8 全通过。
- [x] 独立审查和5056场全域压力验证，修复最高难度阶段计时卡住；更新文档，启动Battle确认HUD/攻击结果/死亡画面。

不新增掩体、潜行、武器系统或学习模型；强度按模拟时间平滑增长并封顶，不通过直接改位置获得命中。
