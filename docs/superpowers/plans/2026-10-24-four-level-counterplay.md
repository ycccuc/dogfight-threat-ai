# 单敌机四级成长与反制实施计划

**批准依据：** 用户已确认《AI成长与反制方案》，要求实现、测试后打开Battle试玩。

**架构：** 纯C#延迟感知和战术选点提供准备位置；攻击状态机统一预警、锁向、冲撞与恢复，只输出FlightInput；独立战斗模型读取攻击编号与有效窗口。Unity捕获快照、显示真实预测走廊、等级与状态。

- [x] 伤害窗口：只有active攻击可伤、每attackId一次、无敌与窗口的子步相交、无窗口只推进时钟。
- [x] 四级profile、10Hz延迟记忆、有限外推、稳定候选点评分与最近四次躲避历史。
- [x] 攻击状态机：起手条件、0.8秒锁向预警、≤0.9秒直线冲撞、1.8→1.2秒恢复、真实脱离及受压重整。
- [x] 公平准入只否决：真实模型验证至少一侧合法躲避，不把实时玩家数据回传战术层。
