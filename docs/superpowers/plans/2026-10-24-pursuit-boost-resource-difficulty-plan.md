# 追击推进、资源惩罚与四级敌机实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 玩家短冲有成本和冷却、长推缓慢线性提速、空槽有可控惩罚；敌机具备有限追赶推进，四级性能和决策差异可实际感知且仍可反制。

**Architecture:** 输入只产生动作意图，推进模型管理资源与计时，FlightModel 是实际速度的唯一写入者。追赶 Boost 与近身 Charge 分开调度；难度快照在动作边界更新，明确区分有限加速度、定速瞄准和锁向冲撞。

**Tech Stack:** Unity 2022.3.62f3c1、C# 纯 Core、现有 NUnit/EditMode/PlayMode 与 .NET 测试工程。

**状态：已实施并完成最终回归及系统键盘输入对照；平衡目标部分未达。** 本文数值是本项目设计，不是原游戏数值。最终Core/EditMode各374通过，PlayMode52通过；原生11局和1728首击轨迹已完成。四级固定绕圈31.54～35.71秒，尚未达到25秒目标，另有部分初态和步长敏感窗口；详见[最终验证](../../03-test/AI追赶推进与资源惩罚验证.md)。资料和现状因果见 [调研](../../02-design/推进资源与敌机难度调研.md)。

## 1. 为什么需要这次重做

现有长按必先获得 2.4 倍短爆，1 秒即到约 26.95；敌机普通追击上限只有 9。受控同向直飞 2.92 秒可额外拉开约 49.28 单位，超过 8 单位攻击半径很多。四级目前主要变化为观察、预测、侧切与恢复，不能弥补这个性能缺口。

本轮同时收紧玩家推进收益、补足敌机接近能力，并给各级可见的新决策。短冲 CD、资源和耗尽惩罚是独立规则，不再把“松键锁”称为惩罚。

## 2. 输入方案与玩家首轮参数

### 推荐方案 A：两个明确动作

- WASD 保留。**按住 Shift 持续推进，按 Space 立即短冲**，两个动作共用推进能量。
- Space 只响应按下边沿；持续按住不会重复冲刺，CD 内按下不排队、不扣能量。下一次需要新按下。
- Shift 从当前实际速度开始提速，不自动送一次短爆。松开则按有限减速度回落，S 刹车优先。
- 短冲优先于长推，短冲期间不再叠扣长推耗能；结束后只有 Shift 仍按住、能量足够且没有耗尽/刹车锁，才恢复长推。低于重启门槛时显示缺能，不偷偷补发短冲。
- 25能量只限制进入或恢复长推；已经合法进入的长推可降到25以下直到0。Space因CD/缺能被拒绝时，不打断进行中的长推；低能量导致长推起手/恢复被拒绝后，不自动等回能起步，须松Shift再按。
- S、死亡、失焦清除尚未消费的动作边沿。失焦同时取消当前Dash/Hold，不退款，退出走有限减速，已欠过热不能消除；回焦后能力键需先松再按。S或耗尽后Shift也必须松开再按。R重开清计时/资源，但当前仍按住的能力键也要松开才重新响应。计时使用游戏时间，失焦冻结游戏时不偷跑恢复。基础操控始终保留。

**备选 B（保留原同键）：** Shift 按下进入 0.12 秒识别窗；窗内松开才执行短冲，达到 0.12 秒则只进入长推，松开长推不追加短冲。按下立即给音画反馈，但不先改速度。其短冲比按下触发多了松键延迟。这是输入取舍，不能同时承诺零延迟短冲和长按完全不吃初始爆发。首轮计划按 A 实施，只有用户选择 B 才替换输入识别任务。

### 建议起点

| 项目 | 当前 | 下一版首轮建议 |
|---|---|---|
| 资源容量 | 归一化 1（等效 100） | 60 个明确能量单位；UI 显示实际量 |
| 快速短冲 | 2.4 倍、0.20 秒 | 目标前速 21.6、0.18 秒，启动扣 25 |
| 短冲 CD | 两次起手最短 0.36 秒 | 两次起手最短 **1.20 秒**，HUD 独立显示 |
| 长推极速 | 27 | **18** |
| 长推增速 | 必先跳到21.6，再0.8秒到27 | 从巡航9起，以 **7.5 单位/秒²**增加，约1.2秒到18 |
| 长推耗能 | 30等效单位/秒，且先有18预付短爆 | 40单位/秒，无预付短爆；满槽从巡航开始可持续1.5秒 |
| 长推转向 | 240°/秒，且覆盖侧滑 | 180°/秒，保留横向物理；普通和短冲仍240°/秒 |
| 松手退出 | 倍率尾段0.26秒 | 实际前速按30单位/秒²回落到普通9，不硬夹 |
| 普通回充 | 约0.5秒后、3秒满 | 停止动力后0.7秒起，每秒20；空槽回满需3秒回充 |

“7.5 线性”指无遮挡直飞、初速9、长推持续供能时的**实际前向速度**，不是仅上限倍率。前向推进补偿其阻尼；转弯、侧滑、碰墙不强行保证世界速度模长。9以下保留正常18的起步加速度并照常消耗长推资源，因此从静止起步不会承诺同样的1.2秒到顶。高于18的短冲尾速进入长推时先有限减速至18，不能瞬间夹速。

正常松开长推的退出尾段仍按180°/秒转向，降回普通速度后恢复240°；短冲及其尾段按240°。过热保留240°操控，不因长推尾段规则再次限制脱离。

新运动命令里的速度统一为**阻尼后的前向目标/上限**，短冲21.6、Charge45和定速瞄准均按此测试；有限加速补偿前向阻尼，不清掉侧滑。普通惯性路径仍允许拖曳使实际速度略低于标称巡航上限。旧接口的5×仍约44.91，新Battle命令到45是约0.2%的口径调整，预测器和新测试须同步，不能混用两种数值作精确断言。

不计回充，60能量只能支付两次25的短冲；从巡航9长推1.5秒，只在18顶速停留约0.3秒。正常退出的尾段仍计入移动收益，调参比较必须包含尾段，不能只比较按住时长。

### 耗尽惩罚

1. 能量因已获准的推进消费首次降到0，进入 **0.9秒过热**。期间禁短冲/长推、停止回能，速度上限降至7.2，以同样30的有限减速度靠近；保留240°/秒转向和S刹车。
2. 0.9秒后恢复普通飞行并以20/秒回能；新的推进起手需至少25能量，并满足松键与短冲CD。**从进入过热时刻起**最早约2.15秒可重新起手；长推耗尽即开始计时。短冲预付扣零若仍完整执行0.18秒，则从该次扣零算最早约 **2.33秒**，不能混用时钟原点。
3. 普通取消或提前松手不触发过热。空槽乱按、低于25的拒绝请求不会重复延长惩罚；S不能抹掉已经产生的过热计时。
4. 若短冲预付25刚好扣到0，先完成已经支付的0.18秒，再开始0.9秒惩罚，不吞掉短冲。长推则在该步的可支付时间用尽时结束，不能白送剩余半步。
5. 不自动扣血、不改变碰撞伤害或0.7秒受击保护，也不新增短冲无敌。

## 3. 敌机新增有限追赶推进

新能力名为 **Pursuit Boost**，只用于接近目标。原来的 **Charge** 仍是完成0.8秒预警后沿实际机头发动的撞击攻击。

- 四级都有追赶推进，等级改变常速、推进性能、频率与使用条件。
- 只允许 Pursuit 阶段启动，Recover 和 Charge 不启动；瞄准期间也不追加追赶推进。
- 每架敌机有60能量，单次追赶启动扣30，停推0.8秒后15/秒回充。短间隔高级能连续用掉储量，但不能无限推进；能量不足不能启动。不把升级当作免费回满。
- 敌机不套用玩家0.9秒/7.2的空槽惩罚；储量不足会失去额外追赶能力，仍正常追踪。它的推进储量和CD可见，玩家可诱导其先交推进再换向。
- 敌机追赶能量只约束 Pursuit Boost；Charge 继续由预警/承诺/恢复周期约束，本轮不另加攻击能量门槛，避免为了等能量再次停住不起手。
- 启动前需要目标方向合适、确有距离/闭合速度收益；预测追赶与减速轨迹，避免在近身阶段用24速度当无预警攻击。偏航误差大于55°、能量或最长时限到达就结束；取消不退费、不返还CD。
- 采用有限加速度40、结束减速度30。**高速追赶及退出尾段转向上限90°/秒**，降到本档常速后恢复普通转向，让玩家可以横切或反向诱导它冲过头。进入Windup的优先交接按下一条单独处理。
- 正常情况下应在进入攻击范围前完成退出。给出可测试的制动预测：步进模拟候选推进+退出轨迹，检查最小距离及触发8范围的时刻；在0.20秒到该档最长时限间选择安全的有限时长，不必固定执行满时长。没有任何安全时长才不启动。不得用“先到某个准备点”作为后续攻击必需条件。
- **突发交接有唯一规则：**玩家突然靠近而在追赶/退出途中满足攻击条件，立即进入Windup并取消追赶能力，不退款；不等减速完成、不夹回常速、不重置0.8秒。Windup把入口实际前速快照为本轮定速（至少该档巡航、至多该档追赶上限），使用本档普通转向上限（不是90°）走侧向路径直到Charge。原追赶CD继续计时，本次预警不变。进入Charge时锁真实机头，目标仍45。
- 完整0.8秒指AI计划发动Charge的前摇，不意味着任何阶段免碰。极近距离玩家主动贴近或双方不可避免的真实接触仍扣血并进入恢复；瞄准安全路径必须在正常有反应空间的局面下验证。不得通过关闭碰撞、停车或重置预警伪造通过。
- 追赶推进用白蓝尾焰/声音，瞄准用现有黄线；画外追赶给方位提示，仍须完整入镜才可准备Charge。冲撞不恢复已删除的红色终点/贴片。敌机旁显示小型推进储量与“推进不可用”反馈，供玩家判断反制时机。

## 4. 四级应该看到的差别

以下为运行时能力档位，不能只在HUD显示等级。常速与实际飞行器转速必须与预测器使用的数值一致。

| 级别 | 常速 / 普通转向 | 追赶最高速度 / 最长时间 / 起手CD | 新能力与明显行为 | 玩家可利用的反制 |
|---|---|---|---|---|
| Lv1 追尾 | 9.5 / 190°每秒 | 18 / 0.45秒 / 4.2秒 | 跟观察到的旧位置，只在远且较直时推进，容易在转向后扑空 | 横切、短冲后换向，利用长恢复 |
| Lv2 截击 | 10.5 / 210°每秒 | 20 / 0.50秒 / 3.5秒 | 根据闭合速度判断追不上，朝有界速度预测点推进，不只沿尾迹走 | 不匀速直飞，推进后改变路线 |
| Lv3 切弯 | 12 / 230°每秒 | 22 / 0.60秒 / 2.8秒 | 评价直追、左右内切三条短期轨迹，保持侧别，减少持续W+A绕圈收益 | 诱导侧切后反向、趁其高速转向不足脱离 |
| Lv4 压迫 | 13.5 / 250°每秒 | 24 / 0.65秒 / 2.2秒 | 利用有限转弯历史与上次可见躲避侧别，改变下一轮切入；根据可见运动/过热尾焰施压，合理花追赶预算 | 保留25能量作应急短冲，换向并利用其推进CD与冲撞恢复 |

所有等级共享追赶90°/秒转向约束、资源上限、0.8秒预警与锁向后不能修正。观察延迟暂沿用0.18/0.12/0.08/0.04秒，刷新间隔0.16/0.12/0.08/0.06秒，预测仍有界。Lv4 不读取Shift/Space、私有燃料值或未来输入；过热线索只有实际可见后才能进入带延迟的观察记忆。

为避免随常速提升把原45冲撞也放大到67.5，**Charge 首轮固定绝对45**，最长0.9秒；相当于原普通9的五倍，不是新各级常速的五倍。0.8秒瞄准保持移动，冲撞开始锁真实机头；恢复维持1.8/1.6/1.4/1.2秒，不能提前用追赶推进抹掉扑空代价。增加性能若导致预警阶段无法主动避免机身接触，要先修路径/退出距离，而非降低预警或暂时关闭碰撞。

成长暂保留0/20/40/60秒与F1–F4固定、F5自动。当前追赶推进及其退出、Windup、Charge、Recover均冻结当前档参数，下一边界才切级；不重置能量/CD，也不瞬时夹速。

## 5. HUD 与可理解的规则

- 本机推进条显示 `能量/60`、25的起手刻度、低量预警；不靠缩短图形条来冒充容量减少。
- 单独显示短冲 `READY / CD 0.xs`，长推 `ACCELERATING`，过热 `OVERHEAT 0.xs` 与恢复门槛。
- 敌机展示当前等级、追赶推进、瞄准、冲撞和恢复的区分；小能量条让“诱导它先交推进”有判断依据。
- 正常试玩展示控制和代价，不放观察延迟、模型接口等实现术语。
