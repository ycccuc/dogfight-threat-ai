## 二、待补清单

> Kenney Pixel Shmup **只有飞机和地形**（实测核对过：24 张飞机单图 + 120 张地形 + 4 张图集），
> 以下都还缺。选定后补登到上表。

| 需要什么 | 候选项 | 备注 |
|----------|--------|------|
| 子弹 / 弹幕 | Kenney Space Shooter Redux（CC0） | 与已有素材同作者，风格天然统一 |
| 爆炸 / 尾焰 / 粒子 | Kenney Particle Pack、Smoke Particles（CC0） | 优先要**多帧序列图**，单图做不出打击感 |
| HUD / 血条 / 雷达 | Kenney UI Pack（CC0） | 雷达小地图是立项书第一阶段的交付项 |
| 音效 | Kenney 音效包（CC0） | 开火 / 爆炸 / 引擎 / 命中 |
| 背景分层（云 / 海 / 岛） | 待选 | 必须能拆 2–3 层做视差 |

> 立项书经费预算里有 **「2D 美术素材购置 400–600 元」**，所以不必死磕免费素材 ——
> 如果一套完整的 2D 空战包能让风格与工作量同时受益，买是合理的。
> **但买之前先在这里登记预选项，买之后保留发票**（结题据实报销）。

## 三、登记字段说明

| 字段 | 怎么填 |
|------|--------|
| 名称 | 素材包名 + 版本号 |
| 来源 URL | 下载页原始链接（不是网盘链接） |
| 授权 | CC0 / CC-BY / MIT / Asset Store EULA / 商用授权 … |
| 需署名 | 是 / 否；是的话写清署名文字 |
| 入库日期 | `YYYY-MM` |
| 存放位置 | 相对仓库根的路径 |
| 用途 | 用在哪一阶段、哪个模块 |

## 四、硬性红线

- ❌ **不接受**「仅限学习使用」「禁止商用」「禁止再分发」的素材 —— 本项目要结题演示并申请软著
- ❌ **不接受**来源不明的素材（搜索引擎扒图、群聊转发、无出处贴图）
- ⚠️ **不要沿用暑期原型 `Undead Survivor` 包**里的角色与音频：它是多语言 ReadMe 的教程/商店资产，
  商用与再发布条款需自行核实，正式项目建议不用
- ✅ AI 生成素材可以用，但同样要在此登记，并注明生成工具与日期（软著材料里要能解释来源）
